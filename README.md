# World Report — 세계 주요 이슈 아카이브

매일 전 세계에서 일어난 주요 이슈를 조사하고 정리한 파일을 보관하는 저장소입니다.

## 목적

정치·경제·사회·기술·과학·환경·전쟁/분쟁·재난 등 다양한 분야에서 그날 가장 중요하고 영향력 있는 국제 이슈를 선별해, 하루 동안의 세계 흐름을 빠르게 파악할 수 있도록 정리합니다.

## 파일 구성

- 파일명 형식: `세계_주요_이슈_YYYY-MM-DD.md`
- 각 이슈는 다음 항목으로 정리됩니다.
  - 발생 및 관련 국가/지역
  - 배경 및 경위
  - 이해관계
  - 왜 중요한지
  - 향후 주목할 점
  - 출처

작업 기준과 상세 규칙은 [CLAUDE.md](./CLAUDE.md)에 정의되어 있습니다.

## 자동화

매일 아침 6시(KST)에 클라우드 정기 작업이 그날의 이슈를 조사해 파일을 생성하고 이 저장소에 커밋·푸시합니다.
